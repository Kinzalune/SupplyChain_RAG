# Meridian Supply Chain RAG System

A Retrieval-Augmented Generation (RAG) assistant designed to query internal quarterly reviews and policy handbooks for Meridian Components Pvt. Ltd.

## Setup & Running Instructions

1. **Clone & Setup Environment**
   ```bash
   git clone [https://github.com/Kinzalune/SupplyChain_RAG.git](https://github.com/Kinzalune/SupplyChain_RAG.git)
   cd SupplyChain_RAG
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
